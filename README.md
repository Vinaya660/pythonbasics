# Beer Servings – Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a beer consumption dataset to understand beer servings and their relationships with other alcoholic beverage consumption and alcohol-related indicators across countries.

## 🎯 Objectives
- Explore and understand the dataset.
- Analyze beer, spirit, and wine servings across countries.
- Identify patterns and relationships between variables.
- Visualize data using Python libraries.
- Practice data cleaning, statistical analysis, and data visualization.

## 📊 Dataset
The dataset contains the following columns:
- `beer_servings` – Beer servings per country.
- `spirit_servings` – Spirit servings per country.
- `wine_servings` – Wine servings per country.
- `total_litres_of_pure_alcohol` – Total litres of pure alcohol per capita.
- `country` – Country name, if included in the dataset.
